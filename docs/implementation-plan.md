# 第一版实施计划

## 里程碑 1：开发环境与空壳 APK

- 准备 Flutter、现代 JDK 和 Android SDK。
- 创建 Android 优先的 Flutter 工程。
- 生成并安装一个空壳 APK，验证 iQOO 设备兼容性。
- 建立自动测试、代码检查和可复现构建说明。

验收：手机能够安装、启动并显示应用首页。

## 里程碑 2：学校登录与会话检测

- WebView 打开学校门户。
- 限制受信导航域名。
- 识别登录成功、登录失效和退出登录。
- 提供“重新登录”和“清除学校登录状态”。
- 避免采集密码、验证码和 Cookie。

验收：用户可在学校官方页面完成登录，应用能明确判断是否已经进入研究生平台。

## 里程碑 3：课表同步原型

- 查询可用学期列表。
- 读取排课结果、课程明细和节次方案。
- 解析周次、星期、节次、教师和教室。
- 对缺少排课信息的已选课程作单独标记。
- 展示同步预览和诊断信息。

验收：真实课表能够无 OCR 导入，复杂周次与网页一致。

## 里程碑 4：本地课表体验

- 今日、周视图和课程详情。
- 本地数据库与离线启动。
- 当前教学周计算。
- 单次停课、调课、补课和本地备注。
- 深色模式和课程颜色。

验收：无网络时可以完整查看已同步课表。

## 里程碑 5：变更检测与提醒

- 新旧快照差异比较。
- 逐项展示课程变化并安全合并。
- 上课前本地通知。
- 同步状态、上次成功时间与登录过期提示。
- 在 Android 后台限制下采用合理的定期检查策略。

验收：学校课表变化不会静默破坏本地数据；通知按用户设置触发。

## 第一版暂不承诺

- 保存学校账号密码；
- 绕过验证码或统一身份认证限制；
- 无条件永久后台登录；
- 学校未写入系统的调课能够自动出现；
- iOS 安装包、桌面组件或应用商店发布；
- 成绩、选课、考试报名等其他教务操作。
