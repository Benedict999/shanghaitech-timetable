# v0.4.0 个性化与数据安全版（2026-09-20）

## 新增

- 使用上海科技大学官网当前红色/白色横版 SVG Logo 替换应用内部的大号文字标题。
- 简洁白、月光黑、上科红三套主题；支持跟随系统、始终浅色、始终深色和跟随主题。
- 从系统相册选择背景，不申请整个存储空间权限；图片在导入时限制分辨率和质量，仅保存在应用本地。
- 背景明暗、缩放、水平位置和垂直位置调整；实心或半透明课程卡片。
- 设置页面集中管理外观、学期时间、备份恢复和版本说明。
- `.sttb` 完整备份包含课表、学期日历、节次时间、主题参数和可选背景图片。
- 恢复前显示学期、安排数量、创建时间和背景状态；SHA-256 完整性校验失败时拒绝写入。
- 恢复课表继续使用 SQLite 事务；若恢复过程中数据库写入失败，会回滚外观和背景。

## 隐私与兼容

- 备份不包含学校账号、密码、Cookie 或 WebView 登录状态。
- 自定义背景不上传服务器。
- 保留 v0.3 的数据库和应用 ID，可覆盖安装并继续读取原课表。
- 当前发布包仍沿用已有调试签名，以便覆盖现有测试版本；尚不是正式签名发行版。

## 验证

- 静态分析无问题。
- 17 项自动测试通过，覆盖 SQLite 事务、日期周次、课表渲染、设置页手机宽度、备份往返和损坏检测。
- 生成独立 v0.4 手机视觉预览，不包含真实课程数据。
- ARM64 发布 APK 仍需在真实 iQOO/OriginOS 上验证相册选择器、系统文件保存/恢复、WebView 登录和覆盖安装。
