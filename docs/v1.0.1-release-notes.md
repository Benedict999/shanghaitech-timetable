## 安装包

- 文件：`shanghaitech-timetable-arm64-v1.0.1-formal-signed.apk`
- 适用设备：ARM64 Android 手机
- 最低系统：Android 7.0
- SHA-256：`F9DAEF24CCF2AC1516ED9ED4E112A338DF43EFC5721FF4EC5D2BBA04A36E3D64`

首次安装可以直接使用。从 v1.0.0 正式版升级时可直接覆盖安装，不会清除本地数据。

如果手机中仍是 v0.4.4 或更早的开发签名版，请先导出 `.sttb` 备份，然后卸载开发版、安装本正式版并恢复备份。开发签名版和正式签名版不能相互覆盖。
