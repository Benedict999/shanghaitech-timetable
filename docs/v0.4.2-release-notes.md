# v0.4.2 背景预览、收藏与性能修正版（2026-09-20）

## 背景预览

- 从相册选择图片后先进入全屏预览，不再立即替换背景。
- 预览支持双指放大、缩小和拖动查看；只有点击“设为背景”才保存，点击取消不改变现有背景。
- 新导入图片最大按 1440×2560、质量 82 处理，兼顾清晰度、内存占用和滚动性能。

## 收藏与历史

- 新增“背景收藏与历史”，使用网格缩略图展示使用过的背景。
- 点击缩略图进入可缩放预览，确认后切换；支持收藏、取消收藏和删除。
- 当前背景有“正在使用”标记；选择“停止使用背景”只关闭显示，不会从历史删除。
- 相同图片按内容哈希去重。最多自动保留 20 张普通历史；收藏和当前正在使用的背景不会自动清理。
- 升级前正在使用的旧背景会在首次打开历史或停止使用前自动登记。

## 流畅度修复

- 原实现会在滑块每次移动时通知整个应用重建并写入本地设置；现在拖动只更新滑块本身，松手后才应用并保存一次。
- 背景图片解码宽度限制为设备实际需要的 720—1440 像素，并使用独立重绘边界缓存静态背景。
- 完全透明时的文字保护从两层模糊阴影精简为一层轻量阴影，网格保护保持不变。
- “课表底板”改名为“背景清晰度”：向右显示更多背景，向左增加蒙层以提高文字可读性。

## 兼容性与范围

- 不改变课表数据库、学校登录、同步接口或备份格式版本。
- `.sttb` 备份仍只包含当前背景，不包含整个历史图库，避免备份文件过大。
- v0.4.0 和 v0.4.1 的课表、主题、背景和备份继续兼容。
