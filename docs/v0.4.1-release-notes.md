# v0.4.1 背景通透与滚动体验修正版（2026-09-20）

## 改进

- 只固定顶部 Logo、同步和设置；周次、日期范围、同步时间、回到本周、星期日期和网格现在作为一个整体上下滚动。
- 每一周保留自己的纵向滚动位置，仍可左右滑动或点击箭头切换教学周。
- 压缩周标题高度，将左右箭头与“第几周”放到同一行。
- 移除周标题独立的高不透明白色面板；周标题到课表底部使用一层连续底板。
- 新增“课表底板”设置，范围为完全透明到 80%；图片背景默认使用 22%。
- 图片明暗与课表底板分开调整，不再需要通过加深图片来弥补白色面板。
- 底板低于 20% 时自动为标题、日期和时间添加对比保护，并加强网格线。
- 课程卡片保持独立的不透明度，不会因为底板完全透明而一起消失。

## 兼容性

- v0.4.0 的课表、主题和背景设置继续保留；旧设置首次读取时采用 22% 的底板默认值。
- 备份格式版本保持为 1，v0.4.0 备份可以恢复；v0.4.1 备份会额外保存底板透明度。
- 不改变学校登录、课表同步、数据库结构或应用 ID。
